## Featured Public Work

### [BOFiP Agentic RAG](https://github.com/Rapha1503/bofip-agentic-rag)

Public project around document intelligence and agentic RAG on a demanding legal/tax corpus. The domain is fiscal, but the engineering work is transferable: ingestion, retrieval, orchestration, source grounding, evaluation and deployment.

- Full-corpus retrieval, not a reduced demo.
- Query planning, source review and targeted retrieval relaunches.
- Cited answers with visible BOFiP sources.
- Streamlit BYOK interface, Docker/Hugging Face deployment.
- Evaluation workflow with reviewed test questions and failure analysis.

**Links:** [Repository](https://github.com/Rapha1503/bofip-agentic-rag) / [Live demo](https://rapha1503-bofip-agentic-rag.hf.space/)
