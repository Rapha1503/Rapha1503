## Agentic AI Focus

I am interested in the engineering layer around modern AI systems:

- **Orchestration:** planning, routing, tool use, state and controlled execution.

- **Evaluation:** test sets, failure analysis, source review and measurable quality loops.
- **Delivery:** simple interfaces, reproducible pipelines and deployable demos.

## Featured Public Project

### [BOFiP Agentic RAG](https://github.com/Rapha1503/bofip-agentic-rag)

An agentic document-intelligence project built on French tax doctrine. The domain is fiscal, but the engineering problem is broader: ingest a difficult corpus, retrieve the right evidence, orchestrate LLM calls, expose sources, and evaluate failures honestly.

| Layer | Work demonstrated |
| --- | --- |
| **Knowledge pipeline** | parsing, chunking, indexing and full-corpus retrieval |
| **Agentic layer** | query planning, source review, targeted retrieval relaunches |
| **Grounded output** | cited answers, visible sources, BYOK Streamlit interface |
| **Evaluation** | curated question set, result review, failure analysis and iteration |

**Links:** [Repository](https://github.com/Rapha1503/bofip-agentic-rag) / [Live demo](https://rapha1503-bofip-agentic-rag.hf.space/)
